# 立项 · 第 1 步：确立核心价值

> 需求定义第 1 层：**定义真问题**。这一步只回答「为什么」，不讨论「做什么」。
> 项目：明日方舟基建换班提醒（代号 `arknights-shift-reminder`）
> 时间：2026-09-29 ／ 作者：agent ／ 状态：**待用户确认**

## 1. 输入

用户原话（2026-09-29）：

> 我现在需要在这个服务器上部署一个轻量的个人使用的小程序，能够提醒我在游戏明日方舟中进行基建换班，换班的逻辑是干员疲劳就换班，但这个不是硬性的逻辑，这个网站上有排版的功能，如果按照排版每 12h，6h，6h 换一次班，按照这个周期换班

参考物：[riic.autos](https://riic.autos/)（可露希尔基建终端）的排班功能；[MAA 基建排班协议](https://docs.maa.plus/zh-cn/protocol/base-scheduling-schema.html)。

## 2. 拒绝盲从：把方案还原成问题

用户原话里的「部署一个轻量的小程序」是**方案**，不是需求。逐层还原：

| 用户原话 | 类型 | 还原后的问题 |
| --- | --- | --- |
| 部署一个轻量的小程序 | 方案 | 我需要在「该换班」的那一刻被叫到 |
| 提醒我进行基建换班 | 需求（表层） | 换班时刻跟我当时的注意力无关，我会错过 |
| 换班的逻辑是干员疲劳 | 方案（游戏机制） | 真正驱动换班的是心情耗尽；但盯着心情不现实 |
| 按排版 12h / 6h / 6h 换 | 方案（执行节奏） | 需要一条**固定、可预测**的时间轴来对齐 |

**5 Whys（追到真痛点）**

1. 为什么要提醒？→ 因为我会忘记换班。
2. 为什么会忘记？→ 换班是**固定的外部时间点**，与当下的注意力无关；手头有事就会被盖过去。
3. 为什么手机闹钟不够？→ 闹钟只有时间，不带上下文（这是第几班、下一班几点），而且忙的时候会被直接划掉。
4. 为什么走 QQ？→ 手机常驻、服务器上已有跑通的机器人通道、不需要新装 App、天然多端同步。
5. 为什么不让 MAA 自动换班？→ 我要的是「我知道该去换」，不是「替我操作」；自动代打有风险，也会让我丢掉节奏感。

第 5 问之后仍停在「应该被提醒」上，痛点成立，可以立项。

## 3. 核心用户与核心场景

核心用户只有一个：**本人**（在校学生、明日方舟玩家、手机与电脑双端）。

| # | 场景 | 具体例子 | 场景特征 |
| --- | --- | --- | --- |
| S1 | 白天在校 | 正在上课或自习，手机在口袋里；轮到换班时需要被叫到 | 游戏不在前台、不方便长时间操作 |
| S2 | 晚上在家 | 快睡觉或已经躺下；夜里还有一班要换，我需要提前知道要不要撑着 | 容易「划掉就忘」 |
| S3 | 换完班后的确认 | 刚换完干员，想确认现在处于第几班、下一班几点 | 需要「当前班次」的上下文 |

## 4. 痛点与机会

| 维度 | 现状 | 差在哪 | 不做的后果 |
| --- | --- | --- | --- |
| 提醒 | 靠记忆 + 手机闹钟 | 记忆被手头的事覆盖；闹钟不带班次上下文 | 漏换一次 = 一整个班次（最长 12 小时）的基建产能损失，干员心情状态错乱 |
| 上下文 | 要开浏览器翻排班表 | 手机上多一步操作，忙的时候被省掉的正是这一步 | 换错班次或漏掉某个房间 |
| 通道 | 服务器已有 AstrBot + 两个 QQ 机器人 | 这套通道只服务聊天，没接到「我的日常节奏」上 | 已经把路修好了却没接上车 |

**机会**：推送通道已经跑通，做一个「只有时间加一句话」的提醒，边际成本极低。

## 5. 一句话价值主张

> **为我自己解决「换班时刻总被手头的事盖过去」的问题，在每次该换班时用 QQ 把「这是第几班、该换人了、下一班几点」送到手边，让我该上线时就能上线。**

外行检验：一个不玩明日方舟的人听完，能复述成「他在游戏里有个每 12/6/6 小时要做一次轮换，会忘，所以要个到点喊他的东西」。

## 6. 核心价值 vs 附加价值

| 层级 | 内容 | 结论 |
| --- | --- | --- |
| 核心 | ① 在正确时刻被叫到；② 一眼知道这是第几班 | **本期只做这两件** |
| 附加 | 提醒里带每个房间的干员名单（从 riic.autos 导出表导入） | 排 V3 |
| 附加 | 读游戏内实时心情，真·「疲劳才换班」 | 排 V4 |
| 附加 | 提醒后回执 / 延后 | 排 V3+ |
| 非价值 | 帮我自动换班 | 不做，见价值边界 |

## 7. 价值边界：明确不解决什么

- **不解决「我懒得换班」**——不代打、不注入游戏，只负责叫醒我。
- **不解决「排班方案好不好」**——不计算最优排班、不评估干员组合，那是 [riic.autos](https://riic.autos/) 这类工具的职责。
- **不解决「我账号里有哪些干员」**——不碰 BOX、不登录游戏账号。
- **不解决「多端同步」**——QQ 本身多端，提醒只发生在 QQ 里。
- **不解决「今天不想按表走」的智能推断**——本期只有一条固定时间轴，要改就改配置。
- **本期不碰游戏账号**——V4 若接入森空岛读取心情，会触碰这条边界，届时必须重新判定，不默认放宽。
