# 审查报告归档

> 用途：存放**独立子代理只读审查**的报告，以及每条意见的处理记录。
> 依据：`docs/architecture/rules.md`、`docs/architecture/extension.md`、`docs/implementation/implementation.md`、项目根 `AGENTS.md`。

## 什么时候派审查

| 时机 | 是否派独立审查 |
| --- | --- |
| 每个子阶段收口 | ✅ 派（只读子代理，审该子阶段全部 commit） |
| 纯文档 / 归档 commit | ❌ 总监自行复核即可 |
| 修复包交付后 | ✅ 派回归检查子代理（只读，只看副作用） |

## 流程（09a 收口流程）

1. 总监派**独立只读**子代理：只读 `git show` / `git diff`，不修改文件、不提交、不跑写操作。
2. 报告按下方模板产出，**每条带 `文件:行号`**。
3. 总监逐条核实，**排除误报**。
4. 有需修项 → 按文件不相交分组生成修复任务包 → 派修复子代理（**先写失败测试**）。
5. 修复后派回归检查子代理 → 总监全量回归。
6. 报告归档到本目录，更新实施文档状态，提交并**立即推送**。
